# RECORD HOTEL
### 음악과 공존하는 나만의 휴식 공간

---

## 1. 프로젝트 소개

**RECORD HOTEL**은 음악 감상과 가벼운 공포 요소를 결합하여 일상 속 스트레스를 건전하고 색다른 방식으로 해소할 수 있도록 기획한 음악 기반 웹 서비스입니다.

현대인들은 학업, 업무, 인간관계 등 다양한 원인으로 스트레스를 경험하며, 이를 해소하기 위해 각자 여러 가지 방법을 활용합니다. 본 프로젝트는 그중에서도 음악 감상과 흥미로운 콘텐츠를 통한 기분 전환에 주목했습니다.

음악은 자신의 감정을 표현하거나 위로받는 수단이 될 수 있으며, 익숙한 일상에서 벗어난 새로운 경험은 또 다른 즐거움을 제공할 수 있습니다. 이에 음악 감상에 호텔이라는 공간적 콘셉트와 가벼운 미스터리한 요소를 접목하여 기존의 단순한 음악 추천 서비스와 차별화된 경험을 제공하고자 했습니다.

사용자는 호텔에 체크인하는 과정부터 시작하여 자신의 기분과 취향에 맞는 음악을 추천받고, 다양한 공간을 탐색하며 음악을 감상할 수 있습니다. 호텔 곳곳에 배치된 미스터리한 요소는 서비스에 몰입감과 재미를 더하는 장치로 활용됩니다.

궁극적으로 RECORD HOTEL은 사용자가 일상에서 잠시 벗어나 음악과 새로운 경험을 통해 자신만의 방식으로 기분을 환기하고 스트레스를 해소할 수 있는 공간을 만드는 것을 목표로 합니다.

## 2. 프로젝트 기획 의도 및 목표

### 2-1. 문제 인식

일상에서 스트레스를 해소하는 방법은 다양하지만, 많은 경우 비슷한 활동을 반복하게 됩니다. 본 프로젝트는 스트레스 해소가 반드시 특별하거나 복잡한 활동일 필요는 없다는 생각에서 출발했습니다.

음악 감상처럼 접근하기 쉬운 활동에 색다른 재미와 몰입 요소를 더한다면, 사용자가 더욱 흥미롭게 휴식 시간을 보낼 수 있을 것이라고 판단했습니다.

### 2-2. 기획 목표

- **건전한 스트레스 해소:** 음악 감상과 가벼운 콘텐츠 체험을 통해 긍정적인 기분 전환의 기회를 제공합니다.
- **개인화된 음악 경험:** 사용자의 기분과 취향을 고려하여 적절한 음악을 탐색하고 추천받을 수 있도록 합니다.
- **차별화된 사용자 경험:** 호텔이라는 독창적인 콘셉트를 활용하여 일반적인 음악 추천 서비스와 차별화합니다.
- **몰입감 있는 공간 구성:** 각 화면을 호텔의 객실과 부대시설처럼 구성하여 사용자가 하나의 공간을 탐험하는 듯한 경험을 제공합니다.

## 3. 주요 기능

### 3-1. CHECK-IN
호텔에 입장하는 첫 화면으로, 회원가입 및 로그인 기능을 통해 사용자별 이용 환경을 제공합니다.

### 3-2. ROOM SERVICE
사용자의 음악 탐색과 추천을 위한 공간입니다. 원하는 곡이나 아티스트를 검색하고 음악을 발견할 수 있도록 구성했습니다.

### 3-3. COCKTAIL BAR
음악 추천을 기다리는 시간에도 사용자가 지루하지 않도록 마련한 공간입니다. 사용자의 기분에 따라 서로 다른 음료를 선택할 수 있으며, 음료를 마시는 상호작용을 통해 추천 대기 시간을 하나의 콘텐츠로 구성했습니다.

### 3-4. MY ROOM
사용자가 자신만의 공간에서 음악을 감상할 수 있도록 구성한 화면입니다. 호텔 객실의 분위기를 시각적으로 구현하고, LP 플레이어와 책장, 벽난로 등의 요소를 배치하여 공간에 대한 몰입감을 높였습니다.

## 4. 사용 기술

## 5. 사용 방법

1. RECORD HOTEL 웹사이트에 접속합니다.
2. 호텔 메인 화면에서 체크인을 진행합니다.
3. 회원가입 또는 로그인을 완료합니다.
4. ROOM SERVICE에서 원하는 음악을 검색하거나 추천 서비스를 이용합니다.
5. 추천 대기 중에는 COCKTAIL BAR에서 기분에 맞는 음료를 선택할 수 있습니다.
6. MY ROOM에서 음악 감상을 즐기며 자신만의 휴식 시간을 보냅니다.

## 6. 실행 방법

본 프로젝트는 Python과 Streamlit을 기반으로 제작되었습니다.

**① 프로젝트 복제**

```bash
git clone https://github.com/zoe4ck/recordroom.git
```

**② 프로젝트 폴더로 이동**

```bash
cd recordroom
```

**③ 필요한 라이브러리 설치**

```bash
pip install -r requirements.txt
```

**④ Streamlit 실행**

```bash
streamlit run main.py
```

※ Supabase 등 외부 서비스와 연결하기 위해 필요한 설정값은 별도로 구성해야 합니다.
